Yash Trivedi Portfolio Design Guide
Project
Personal portfolio for Yash Trivedi, Full Stack Developer.

Visual direction: dark, minimal, cinematic, editorial. Match the approved hero section: charcoal background, oversized cream typography, and restrained accents.
Color Palette
Color	HEX	Use
Background	#1A1A1A	Main page background
Surface	#232323	Cards and alternate sections
Primary cream	#F4E7CD	Main headings and highlights
Secondary cream	#E8DCC2	Secondary accents and outlined elements
White	#F9F9F9	Body text
Muted	#8E8677	Supporting text and metadata
Border	#3A3A3A	Dividers and subtle borders
Accent peach	#FDC3A1	Selected links and interactive highlights


Color rules
- Keep the interface predominantly dark.
- Use cream for major headings and important text.
- Use white for readable body copy.
- Use muted text only for secondary information.
- Use peach sparingly for small accents and interactive states.
- Do not introduce extra colors, neon shades, bright gradients, or colorful shadows.
Fonts
Bebas Neue
Use for hero typography, large section headings, project titles, and display numbers.

Google Fonts: https://fonts.google.com/specimen/Bebas+Neue
Inter
Use for navigation, buttons, paragraphs, descriptions, labels, and UI text.

Google Fonts: https://fonts.google.com/specimen/Inter
Typography rules
- Use Bebas Neue for large display headings.
- Use Inter for supporting and functional text.
- Keep heading hierarchy clear and consistent.
- Use uppercase display headings where appropriate.
- Scale typography responsively. Prevent text clipping on smaller screens.
Design rules
- Maintain the dark editorial look across every section.
- Use generous spacing and clean alignment.
- Keep layouts minimal and typography-led.
- Use subtle borders instead of decorative dividers.
- Keep cards and panels simple.
- Use consistent button styles and restrained hover states.
- Avoid glassmorphism, glow effects, excessive shadows, and unnecessary decoration.
- Keep animations smooth and restrained.
- Ensure every section works on desktop, tablet, and mobile without clipping or horizontal overflow.
